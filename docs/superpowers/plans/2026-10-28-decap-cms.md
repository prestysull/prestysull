# Prestysull Decap CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir a la V10 de Prestysull una interfaz `/admin/` con Decap CMS y Decap Turbo Free para que una administradora edite textos, imágenes y enlaces de videos sin tocar GitHub o código.

**Architecture:** Siete archivos JSON contienen únicamente contenido editorial y son validados por Zod antes de llegar a los componentes. Los módulos `src/data` conservan sus exportaciones actuales y combinan ese contenido con reglas financieras protegidas, reduciendo cambios en consumidores. Decap CMS 3.17.3 edita los JSON y `public/uploads/`; `turbo-github` guardará en `main` cuando exista el `turbo_site_id` real.

**Tech Stack:** Astro 7.4, TypeScript estricto, JSON + Zod (`astro/zod`), Decap CMS 3.17.3, Decap Server 3.11.6, YAML 2.9.1, Node test runner, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-28-decap-cms-design.md`

## Global Constraints

- Trabajar solo en `codex/decap-cms`, basada en V10 `ebe6498`; no cambiar ni desplegar `main`.
- Mantener V5, V9, V10, ramas históricas y archivos no rastreados del usuario intactos.
- Decap Turbo Free: un sitio, un asiento, costo S/ 0; no compartir credenciales.
- Backend final `turbo-github`, rama editorial `main`; `turbo_site_id` queda como marcador hasta completar la cuenta externa.
- No editar desde CMS fórmulas, tasas, seguro, capital mínimo/límite técnico, 7/14 días, 8/4 cuotas, calendario, advertencia financiera, iconos técnicos, HTML, CSS o navegación.
- Mantener WhatsApp como único canal de captación; el CMS no crea formularios ni almacena prospectos.
- Archivos CMS válidos deben existir desde el primer commit; contenido inválido hace fallar tests/build.
- Medios CMS viven en `public/uploads/`, máximo 2 MB, rutas `/uploads/...`, texto alternativo obligatorio.
- Videos son enlaces HTTPS externos; no iframes, autoplay, cookies ni scripts de terceros.
- La sección de videos no renderiza ningún nodo cuando está desactivada o no tiene elementos visibles válidos.
- Conservar SEO, accesibilidad, teclado, `prefers-reduced-motion`, mobile-first y ausencia de desbordamiento desde 320 px.
- No afirmar autenticación Turbo ni publicación automática como verificadas hasta probarlas con el UUID y hosting reales.

## Review Focus

- JSON incompleto, tipos incorrectos, texto vacío o más/menos de las tres escenas/seis etapas debe fallar con el archivo y campo identificables; Task 1 lo fija con fixtures inválidos.
- Un administrador que introduzca `javascript:`, HTTP, una ruta fuera de `/uploads/` o caracteres peligrosos no debe crear enlaces/medios inseguros; Tasks 1, 3 y 5 lo fijan con validación y pruebas de renderizado.
- Los nombres de campos de `config.yml` deben coincidir exactamente con los JSON y nunca exponer reglas financieras protegidas; Task 4 compara ambos árboles de claves.
- `BASE_PATH=/revision/` no debe romper imágenes CMS, `/admin/` ni enlaces internos; Tasks 3 y 4 lo fijan con build/preview bajo subruta.
- Marcador `turbo_site_id`, fallo de despliegue o ausencia de conexión externa no debe presentarse como CMS productivo; Task 6 lo registra como bloqueo y prueba que la guía no promete activación.

## File Map

- `src/content/cms/*.json`: contenido único que Decap edita.
- `src/lib/content.ts`: esquemas, tipos, validación y exportación `cmsContent`.
- `src/lib/cms-media.ts`: normalización de rutas `/uploads/` con `pathUrl()`.
- `src/data/*.ts`: adaptadores compatibles con los componentes existentes.
- `public/uploads/*`: recursos iniciales optimizados y futuras cargas.
- `public/admin/index.html`: aplicación Decap fijada a 3.17.3.
- `public/admin/config.yml`: backend, medios y colecciones editoriales.
- `src/components/Videos.astro`: sección opcional de enlaces externos.
- `tests/content.test.ts`: contrato editorial, seguridad y reglas protegidas.
- `tests/cms-config.test.ts`: sintaxis y correspondencia config/JSON.
- `tests/browser/site.spec.ts`: regresiones públicas, admin, medios y videos.
- `docs/cms-administracion.md`: manual de la administradora.
- `docs/cms-turbo-setup.md`: alta gratuita y conexión externa.
- `docs/cms-verificacion.md`: evidencia y pendientes honestos.
